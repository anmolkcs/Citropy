# Security

Citropy runs coding agents with access to your files, terminals, and browser, so security problems matter.

## Reporting a vulnerability

Report it privately at [github.com/tinuxongit/Citropy/security/advisories/new](https://github.com/tinuxongit/Citropy/security/advisories/new). Please don't open a public issue. Include the Citropy version, your operating system, and the steps that show the problem.

## Supported versions

Only the latest release receives security fixes. The app's update button installs it.
